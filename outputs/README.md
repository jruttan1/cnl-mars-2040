# CNL radiation outputs

- **mission_radiation_environment.csv** — frozen v1.1 baseline for Strategies A–D. This presentation copy matches the working CSV in `../data/processed/`.
- **charts/** — eight current PNG figures. Older King-only figures are separate in `charts/historical/`.
- **model/baseline_validation.md** — numerical checks and interpretation limits.
- **model/baseline_manifest.json** — frozen CSV checksum and provenance. Recorded paths refer to the project root.
- **model/** — supporting audits and reusable numerical results; large intermediate tables are generated locally and excluded from Git.

The baseline contains both SAPPHIRE scenarios, six aluminium shielding levels and nine timing variants for each historical template: August 1972 (264 hours, default) and GOES-10 October–November 2003 (336 hours). Select one `historical_template`, scenario, shielding level and timing variant; do not sum variants. `estimate_type == "central"` selects the default timing assumption. Hours are measured from storm start; the default 72-hour display covers storm hours 48–120.

Dose rates and cumulative values describe an idealized tissue target, not verified astronaut whole-body doses. `data_quality` describes the historical timing observations; all doses are modeled.

From the project root:

```python
from radiation_model import load_baseline, baseline_interval_dose
baseline = load_baseline()
print(baseline_interval_dose("SAPPHIRE-1-in-100", 0.4, 16, 23,
                            baseline=baseline))  # 3.8272391527 tissue-target mGy
```

Edit individual figures in `../charts/`. Keep the frozen baseline unchanged while developing strategy code. Generated `.txt` captions were removed; plotting scripts may recreate them, and Git ignores them.

## Strategy A results

`strategy_a/summary.json` and `strategy_a/event_log.csv` contain the most recent mission run. `charts/09_strategy_a_mission_timeline.png` shows completed/aborted attempts and cabin time. Regenerate with `python run_strategy_a.py` from the project root. These outputs are an operational simulation using the frozen baseline; they are not new transport results or clinical predictions.

## Exploratory 2003 BFO proxy

`model/exploratory_bfo_october_2003_goes10.csv` is a separate **unverified organ-transfer experiment**, generated by `python bfo_proxy.py`. It contains both SAPPHIRE scenarios at 20 g/cm², all 336 GOES-10 hours and nine timing variants. Columns prefixed `bfo_proxy_` separate absorbed mGy from Gray Equivalent mGy-Eq; the original tissue-target columns are retained for provenance. Reference organ values are supplied by the user and could not be verified in the saved OLTARIS reports. This file is not used by the mission simulator, must not be applied to EVA shielding, and does not establish compliance with medical limits.
